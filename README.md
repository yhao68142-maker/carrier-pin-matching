# 载条定位销尺寸匹配

独立网页模块：STEP/STP 实体解析、定位销候选识别、三维预览、轴心复核及 Excel 双尺寸匹配（各 ±0.01 mm）。

## 测量定义

以载条平面为基准，最长直边为横向 X，平面内正交方向为业务 Y。图四对应 X=136.9 mm、Y=57 mm（原 CAD 截图为 dZ）。斜向中心距 148.29 mm 和外形 180×92 mm 不用于定位销匹配。

使用 OpenCascade 读取解析圆柱轴线，筛选垂直基准面的外圆柱并合并同轴候选。运行时直接调用 OCCT，避免加载 CadQuery 的额外依赖；CadQuery 仅用于生成测试模型。视图使用三角网格，但测量不使用网格或图片像素。每次测量需要用户确认候选轴心及方向；自动基准不适合所有复杂装配，建议导出单个载条。STL 和截图不支持精确轴线测量。

导入采用分块复制，同一进程只同时解析一个模型。空响应、代理错误及连接中断会显示中文提示，不自动重复上传。日志记录读取、轴心识别及预览阶段，便于定位中断。桌面 12.4 MB 载条实测读取成功，两根 Ø2.9 mm 轴心的 X/Y 为 136.90000000000416 / 57.00000000000002 mm；Windows 独立进程内存峰值由约 509 MB 降至约 383 MB（不等同于 Linux 云端内存）。

匹配采用十进制比较，X/Y 各允许 ±0.01 mm，包含边界，两个方向必须同时满足。不按显示精度舍入，不自动交换 X/Y。标准 136.9×57 时，136.91×56.99 命中，136.91000001×57 不命中。页面保留原始测量值，结果显示 ΔX/ΔY，手工查询明确标为手工值。公差只用于匹配，不是 CAD 测量精度承诺。

## 本地启动

需要 Python 3.12。推荐使用虚拟环境：

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app:app --host 127.0.0.1 --port 8876
```

打开 http://127.0.0.1:8876 。模型仅发送到此本地服务，在临时目录解析后删除。

## 尺寸库

已从用户 Excel 抽取 65 条尺寸记录。`data/catalog.json` 为内嵌运行数据，不需要每次上传 Excel。仓库为私有，仅包含匹配所需字段及来源，不包含完整工作簿。缺少文件时页面显示 0 条，不伪造数据。

重新抽取时安装 openpyxl，然后运行：

```powershell
python tools/import_catalog.py "通用料盒信息&压料机构进度.xlsx"
```

提取“治具料盒信息统计”和“治具料盒信息统计（CB端）”中 D 列为“载条定位销尺寸”的记录，E 列解析为 X*Y。合并单元格追溯关联项目代码、机种；保留原字段和单元格来源，同尺寸多机种全部展示。源 Excel 始终只读。

## 部署说明

已提供 `render.yaml`，可在 Render 中选择 New → Blueprint 并连接此私有仓库。配置为免费 Docker Web Service、新加坡区域，启动端口读取平台 PORT，健康检查为 `/healthz`。免费实例资源有限，较大 STEP 需验证内存；不自动升级付费计划。实例休眠后的首次请求可能需要等待启动。

公网版本允许访问者读取这 65 条匹配记录，上传模型在服务器临时解析后删除。源码仓库仍为私有。

本项目需要 Python CAD 后端，GitHub Pages 无法单独执行 STEP 解析。可以在支持 Python 3.12 和上述依赖的机器启动，或使用 Docker。默认监听本地；公开部署前应配置登录、请求限流和资源隔离。

定位销间距相同不代表载条完全通用，需继续核对销径、销位方向和产品穴等结构。

## 四项尺寸对比

网页同时比较销钉 X、Y 与载条外形长、宽，四项各自允许 ±0.01 mm。外形在载条基准平面中对最大基准面所属实体作解析几何包络测量，长取较大边，宽取较小边；不从三角网格或图片取尺寸，不把高度计入长宽。复杂装配必须复核基准实体。

最新尺寸库来源为用户提供的“通用料盒信息&压料机构进度 (1).xlsx”。CB 端记录读取同一合并备注中的“载条外形尺寸”；合并备注适用于该备注覆盖的全部机种，不要求同组销位相同。总表优先按完整机种名称关联 CB 端备注；其次仅在项目代码和销钉尺寸一致且外形标准唯一时关联，不能用 BOSA 端载条或料盒尺寸替代。66 条记录中 56 条有可确认的外形标准，其中 1 条仅有穴位尺寸，不能当作销钉 X/Y；55 条有四项标准，11 条显示资料不全。原始单元格引用保留在结果中。

四项齐全时以四项平均相对偏差计算相似度，四项全部符合优先排列，再按相似度、偏差排序。缺少标准的记录不参与综合评分和排名。样例实际长宽为 180×92 mm，虽然销钉为 136.9×57 mm，但资料中该销位的候选外形为 185×92 mm，因而不能报告四项符合。


## 导入进度与简化预览

页面通过 `/api/jobs` 上传，返回任务编号后按当前阶段轮询，避免把长时间 CAD 处理绑在一个 HTTP 响应上。上传百分比来自浏览器实际发送字节，解析显示阶段与总用时；整体进度按阶段权重估算并明确标注，上传占 0–15%，结果返回后才显示 100%。重连期间不倒退，阶段未变化时不按时间虚增。CAD 工作进程有五分钟上限；每次完成释放原生内存，原 STEP 立即删除，临时结果最多保留十分钟。服务重启后任务失效会提示重新导入，不使用数据库。

所有轴心和外形计算仍在完整 STEP 上进行。预览最多选择 160 个面积不小于 2 平方毫米的大面，平面内小于 2 平方毫米的孔环略去，用绝对 0.3 mm、角度 0.5 rad 的粗网格，最多返回三万个三角面。小刻字、滚花、细小圆角及部分复杂细节不会完整显示，不能把该预览当作加工图。读取及转换 STEP 本身仍需处理原始文件，无法保证完全跳过刻字的读取成本。

用户提供的 400G OSFP PSM4 模型预览由 1,430,408 面降为 2,908 面，本机处理由约 17.5 秒降至 7.8 秒；1.6T ALN 模型由 66,552 面降至 1,893 面。两份文件优化前后轴心与外形结果一致。云端时间还受上传网络、实例冷启动和 CPU 配额影响。
